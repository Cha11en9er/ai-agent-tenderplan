# Агент Tenderplan — Оценка тендеров

Python-скрипт на **Playwright** для автоматизации работы с [tenderplan.ru](https://tenderplan.ru): поиск по тендерам, скачивание документов, **оценка тендеров агентом**: агент открывает каждый тендер, скачивает все файлы + описание + даты и т.д., анализирует данные и даёт вердикт — браться за тендер или нет. Файлы скачиваются PDF/DOC/XLS **в оригинальном виде**.
---

## Конечное видение проекта

1. **Агент запускает парсер** — парсер проходит по каждому тендеру, который ещё не отмечен как «просмотренный».
2. **Сбор данных** — для каждого тендера скачиваются:
   - Все прикреплённые файлы (документация, ТЗ, спецификации)
   - Описание тендера
   - Даты (срок подачи, дата окончания)
   - Цена, заказчик, и другие метаданные
3. **Анализ агентом** — когда все данные о тендере собраны, AI-агент анализирует документы и даёт вердикт: **браться за тендер или нет** (с обоснованием).
4. **Результат** — пользователь видит список тендеров с вердиктами и может принять решение.

- Пользователь посмотрит, как работает парсер, что нужно доработать, и какие файлы скачиваются

## Переменные окружения (.env)

Для **main.py** .env **не обязателен**: скрипт использует uth.json для восстановления **сессии** и cookies браузера.

Для **save_auth.py** нужны LOGIN и PASSWORD.

Настройки для **main.py**: TENDER_SEARCH_QUERY (по умолчанию питание), TENDER_SEARCH_WAIT_SEC (по умолчанию 10) — см. в разделе описания работы скрипта.

## Логика main.py

### 1. Восстановление из uth.json

- Если в папке есть файл **uth.json**, браузер запускается с **storage_state=auth.json** (cookies + localStorage).
- Переход на **https://tenderplan.ru/app**. Если URL **не** содержит путь приложения (/app), значит сессия истекла — переход на **https://tenderplan.ru/**, ожидание **ручной авторизации** через браузер (до **10 минут**). После успешного входа cookies сохраняются в **uth.json** — следующий запуск будет автоматическим.

Автоматический логин/пароль из .env в **main.py не используется**; для автоматизации авторизации используйте **python save_auth.py**.

### 2. Поиск по тендерам

- После перехода на **/app**, в поле **input[class*=" Searchbar__searchInput\]** вводится запрос **питание** (переменная окружения **TENDER_SEARCH_QUERY**, по умолчанию питание).
- Ожидание **TENDER_SEARCH_WAIT_SEC** секунд (по умолчанию **10**), чтобы загрузился список тендеров.
- Контейнер — **TenderPlate__container** внутри **ReactVirtualized__Grid__innerScrollContainer**; список тендеров **виртуализированный**.

### 3. Анализ статуса на тендере (TenderHeader__selectedMark__inner)

Чтение статуса **span[class*=\TenderHeader__selectedMark__inner\]** (два варианта: **<Выбрать метку>** и **<Проверено>**).

| Статус в UI | Действие |
|----------------|----------|
| **<Выбрать метку>** (функция choose_label) | Тендер не обработан — перейти к скачиванию документов, анализ данных, сохранение в enders_data.json. |
| **<Проверено>** уже в статусе (функция erify) | Тендер **уже** обработан. Если этот id **уже есть** в JSON — пропустить (дубликат). Если id нет — добавить в JSON. |
| Другой статус (unknown) | Логировать: статус неизвестен, добавить в базу с пометкой. |

Параметр ** ender=** извлекается из URL страницы тендера.

### 4. Возврат к списку

Для статуса **<Выбрать метка>** тендер **<Проверено>** выполняется **скачивание** всех документов (если их 0 — просто пометить как обработанный).

1. **Escape**, закрыть окно выбора статуса в **TenderHeader__updatingMarkButton**.
2. В меню — выбрать **data-seo-event=\relation-marks-set\** и **<Проверено>** (цвет 
gb(206, 72, 72), красный кружок).

После go_back скрипт возвращается **на тот же** ender_id, пропуская **plate_skip** (виртуализированный список).

Ожидание **4-8 сек** между тендерами.

### 5. Сохранение результатов

- ** enders_data.json** — массив записей с полями **id**, ** itle**, **url**, **price**, **deadline**, **downloaded_files** (имена скачанных файлов).
- Папка **downloads/<id>/** с файлами **{id}-{имя_файла}**.

## Технические заметки

- Классы с суффиксами типа ___1Sv0R — это CSS Modules; в скрипте используются **частичные селекторы** [class*=\...\], чтобы не зависеть от хэшей.
- Если виртуализированный список не показывает нужный тендер, скрипт скроллит контейнер.
- Дампы HTML для отладки — можно открыть в браузере для анализа.
